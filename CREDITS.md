## Sounds
Every Sanctuary sound (rain, ocean, flowing water, quiet forest, soft piano, etc.) and every activity
sound is synthesised live with the Web Audio API by code in `index.html`. No recordings or samples, so
no third-party licences apply.

## Illustrations
Round 3 additions, all drawn in code for Present (SVG or canvas), no third-party artwork: the Settings gear,
task icons, the mantra lotus, the squishy ball, fireflies and dusk backdrop, the zen garden (sand, stream,
ferns, moss, stones), scratch-art backgrounds, celebration sparkles and the composer microphone and send icons.
The ambient loops for rain, crickets and river in activities are synthesised with the Web Audio API.

The threads (tangled → named), the path zoom-out, the seedling, jar and chat empty states are SVG drawn
in code for Present. No third-party artwork.
